# Peněženka v kostce

Hry o penězích a finanční nezávislosti pro teenagery. Zdarma, bez registrace, rovnou v prohlížeči.

- **Díl 1: Krysí závod** (`dil-1/`): rozpočet, rezerva, půjčky, podvody
- **Díl 2: Burza** (`dil-2/`): akcie, ETF, poplatky, krach a páka
- **Díl 3: Moje bydlení**: připravujeme
